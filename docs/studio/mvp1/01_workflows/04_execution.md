# Node 4: 真实运行与观察 (Execution & Observation)

## 1. 业务目标
执行通过 Compile 的 Skill，使用真实的大模型（如 Claude, Gemini, DeepSeek）处理真实的测试输入。PM 需要在这个阶段观察整个 Agent-Loop 的运转是否符合预期，特别是多轮 Nudge（纠偏）、工具调用过程、以及每个阶段的耗时。

## 2. 界面元素与交互逻辑

### 2.1 控制区
- **[ Run ] 按钮**: 当 Compile 通过并且选择好合法的测试输入文件后，点击此按钮开始真实运行。
- **运行状态指示**: 显示 "Running...", "Paused", "Failed", "Success"。

### 2.2 Trace Timeline (时间轴面板) 与布局展现
这是本节点的核心组件，需要实时流式（通过 WebSocket）渲染底层引擎触发的事件。Trace 具有强烈的时间流与层级嵌套属性，因此**必须采用竖版构图**以保证信息呈现的清晰度。

针对不同的布局流派，Trace 面板的展现形式如下：
- **在 VS-Code 流派下 (标签页切换)**: 主编辑区顶部存在 Tab 栏（如 `[ 源码 ]` | `[ Trace Timeline ]`）。运行开始时，主舞台自动从源码切换至 Trace 标签页。下方 30% 的画布保持不动，节点随执行进度呈现“呼吸灯”和“红绿状态”，PM 可做到“上方看详尽竖排日志，下方看全局进度”。
- **在 Canvas-first 流派下 (侧边栏替换)**: 绝对不能采用底部抽屉（横向太扁，竖向空间不足）。当运行开始时，Trace 面板应当从右侧滑出，或者**直接替代原有节点属性 / Monaco 编辑器所在的局部侧边栏位置**，占据足够的竖向高度。主画布向左侧稍微挤压或保持不变，让 PM 依然能“左看全景大图灯光闪烁，右看竖排瀑布日志”。

**底层事件详情**:
- **阶段分隔**: 清晰划分出不同的 Phase (如 Phase 1: `segmentation`, Phase 2: `event_extraction`)。
- **具体动作**:
  - `llm_call`: 展开可看大模型的原始回复。
  - `tool_call`: 展开可看调用的函数及传入参数。
  - `nudge`: **需要高亮提示**，让 PM 清楚地知道哪一步大模型跑偏了，系统触发了多少次强拉回。
  - `validator`: 显示阶段性校验的结果，如果失败会触发 Retry。
- **性能与成本**: 在每次执行完毕后（或实时），展示当前阶段消耗的 Token 数与执行时间。

### 2.3 节点产物与 Context 连线透视 (Edge Inspection)
在任何 Predict 或 Run 跑完（甚至中途报错暂停）后，PM 需要排查数据流转。去海量 Trace 里面捞 Context 数据是噩梦。
- **交互形式**: 拓扑图上，节点与节点之间的**连线上会出现一个小圆点（或数据包 Icon）**。
- **功能**: 点击这个连线点，立刻在侧边弹出一个纯净的 JSON Viewer，展示**上一轮跑完时，从上游节点传递给当前节点的 Context "大黑板" 数据是什么**。
- **价值**: 这是 PM 验证 `io.outputs` 和 `context_bridge` 是否如预期工作的最直观抓手。

### 2.4 Agent-Loop 微观拓扑展开 (LLM Node Micro-Topology)
`Agent-Loop` 不是一次简单的 LLM 请求，而是一个复杂的认知循环。PM 需要清楚看到这层黑盒里发生了什么。
- **交互形式**: 单击画布上的一个 LLM 节点，该节点不仅在右侧展示 Trace，自身在画布上也会**展开为一个“微观拓扑图 (小图)”**。
- **微观图内容**: 展示底层 `deerflow` 引擎赋予该节点的完整循环周期：
  1. `update_working_memory` (计划步骤)
  2. `tool_calls` (每一个被调用的工具/Sub-skill 就是一个小节点)
  3. 真实的 `LLM Reply`
  4. `md2json` (如果触发了格式修正，高亮显示)
  5. `validator` (质检结果)
  6. `finish_task` (自检结束)
- **价值**: 让 PM 能直观看到“每一轮循环大模型到底在干嘛”，彻底打破 Agent 的黑盒。

### 2.5 Prompt Inspector (提示词透视仪)
- **触发点**: 点击 Timeline 中的 `llm_call` 节点或微观拓扑中的具体动作。
- **呈现形式**: 三标签页的弹出面板：
  1. **原始模板 (Template)**: `SKILL.md` 中写的带变量的原始 Prompt。
  2. **变量字典 (Variables)**: 运行时实际注入该 Prompt 的具体参数值。
  3. **最终文本 (Rendered)**: 最终发给大模型的纯文本。
