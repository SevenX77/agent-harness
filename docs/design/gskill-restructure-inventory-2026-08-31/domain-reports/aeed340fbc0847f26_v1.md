**M-E1 `run-orchestration`（从 `run_manager.py` 2374 行切出 3 个）**

- **E1a `RunProcessSupervisor`** — 存在理由：进程生命周期是独立可失败的原子（fork/claim/terminate/liveness）。own 事实：worker 进程句柄、OS 目录锁、存活性。公开能力：`spawn(run_dir, payload) / terminate(run_id) / is_alive(run_id)`。依赖：`hold_run_liveness`（`run_manager.py:210`）。规则动作：一个 run_dir 至多一个活进程。承诺与失败：进程死 ≠ run 失败（liveness 才是判据）。证据：`:191-220,:727,:1386,:1496`。生命周期：与进程同生死。
