# 域一 · gskill 格式域

## ① 应然

| 项 | 内容 |
|---|---|
| **Effect** | 给定一个目录 → 判定是否合法 gskill，产出唯一 typed manifest/AST |
| **own 的事实** | 目录布局、每文件语法、skill/graph identity、拓扑声明、IO schema 声明、语法条目↔错误码映射 |
| **概念词表** | skill root / graph / graph_id / phase(`id`,`depends_on`,`output`) / mode(logic\|agent\|subgraph) / io.inputs\|outputs / artifacts / registry / schema_version |
| **膜** | 一个 reader + 一个 writer，二者共用同一份 typed manifest；宿主（Studio/CLI/MCP/agent）不得自带 parser、不得自带模板 |

## 两域交叉的一条总结论

两个域的违章模式**同源**：一个概念被多个 owner 复制（格式模板 5 份、parser 4 份、错误码词表 4 套、诊断 DTO 2 份、preflight 子集 3 份），而复制的**触发条件都是「某个面需要一点该概念的知识，就地自建了一小份」**。新仓在格式域上已系统性收敛（1 parser、1 模板、writer 复用 reader 的 manifest、载体禁 XML 拓扑标签），在诊断域上做对了单出口与 DTO 形状，但**新增了两个反向违章**：无码无坐标的 `HostNativeContractError`（④第 4 项）与被否决的 `DEFAULT_LLM_ROLE` 回归（D-T1）。后者是本次对账中唯一「新 engine 已经违反刚生效的用户裁决」的项，建议列为交接前置门。
