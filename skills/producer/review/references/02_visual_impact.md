# 视觉冲击力标准：潜空间锚点与机制定义

## 第一性原理：视觉即权力结构（Visual Power Dynamics）
> 描述必须从**画面压迫感与情绪机制**出发，绝不能受限于**现实物理的合理推断**。
"合理推断"会产出平庸的描述，导致逻辑坍缩；"机制定义"才能在潜空间中精准锚定震撼的画面。所有的视觉尺寸、光影、材质，本质上都是在向观众传递角色之间的**权力结构（谁是猎物，谁是猎手）**。

## 武器/道具尺度法则：比例夸张机制

### 法则一：打破物理边界的视觉锚点
- 武器/道具的尺寸必须**超出常理**，作为高密度的视觉锚点来传递“不可战胜”的绝望感或“绝对碾压”的爽感。
- *错误示范*：3米高的诡异配1米的剪刀（比例失调，像拿指甲剪）。
- *正确机制*：3米高的诡异 → 必须配备2.5米-3米的生锈巨型剪刀（等身尺度）。
- *潜空间参考*：进击的巨人的体型压迫、黑暗之魂（Dark Souls）的巨型BOSS武器、剑风传奇的巨剑。

### 法则二：材质与历史感的语义压缩
- 材质描述不是为了写实，而是为了**语义压缩**。
- "生锈" = 历史感 + 破伤风联想 + 痛苦的死法 = 恐怖倍增。
- 材质必须具体且带有情绪指向：不是"一把剪刀"，而是"布满铁锈的、缝隙间嵌着暗红色干涸血块的巨型刑具"。

## 环境张力标准：光影作为情绪引擎

### 光照即情绪（Lighting as Emotional Engine）
- 不要只写“天黑了”，要定义**光影机制**。
- **恐怖/压抑场景**：低照度 + 强明暗对比（Chiaroscuro） + 极冷色温（幽蓝/死灰/惨绿） + 弥漫的体积雾（Volumetric Fog）。
- **爽点/爆发场景**：高对比度的轮廓光（Rim Light） + 极具侵略性的暖色爆发（暗金/猩红） + 画面中心的高光过曝。

### 空间尺度对比
- 危险区的预警信号必须视觉化：墙体上不符合几何规律的裂痕、空气中悬浮的灰烬、光源的非自然闪烁。
- 越安静的环境，越需要通过高密度的视觉细节（如：角落里一滩未干的黑色粘液）来锚定危险。

## 力量展示标准：超凡现象的具象化

### 超凡力量的视觉化协议
- 能力激活 → 必须有**高密度的视觉特效锚点**（如：空间扭曲、高频电流、几何状的能量阵列）。
- 力量碾压 → 放弃抽象的“很强”，改用**物理破坏的规模**（如：一拳将承重墙轰出蛛网状的深坑）和**体型对比**来传达。

### 恐怖实体的画面规则
- **体型压迫**：以人类日常物品为参照物，明确标注尺寸（"比超市货架高出半个身子" 远胜于 "非常高大"）。
- **恐怖谷效应（Uncanny Valley）**：诡异的恐怖来自"不该是这样但它就是这样"的错位感（如：惨白纸人脸上鲜艳如血的腮红）。

## 零样本压力测试：审核检查清单
- [ ] 武器/道具的尺寸是否打破了现实物理限制，形成了绝对的视觉压迫感？
- [ ] 场景描述是否包含了明确的光影机制（色温、对比度、光源类型）？
- [ ] 非人实体的体型是否有具体的日常参照物（如：货架、汽车）？
- [ ] 力量展示是否被压缩成了具体的视觉特效（光芒、气流、物理破坏）？
- [ ] 所有的视觉细节是否都服务于该场景的核心情绪（爽、恐惧、压抑）？
