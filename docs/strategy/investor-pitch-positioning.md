## 0. 两条大方向约束(用户定,务必遵守)
1. **不贬低 AI Agent**:Agent 很强,强在**自主探索**(开放任务、一个聪明大脑自己闯)。我们讲的是**上限错配(mismatch)**——它优化的方向(自主)和企业生产要的(可控复现)不在一条轴上,**不是缺陷(defect)**。禁止"跑偏/漏步/幻觉/不靠谱实习生"这类贬低式 framing。站"另一个需求象限",不站"Agent 的反面"。
2. **内容科技出身,作背景不外喊**:我们本身是内容科技公司(元宇宙/数字人/短剧平台)。这套引擎**源于自己生产端的真实刚需**——用作可信度锚点("自己挖金矿才造的铲子"),但**不强打元宇宙/数字人这些标签**(投资人对这些词警惕)。需要时点一句"我们是内容科技公司,引擎源于生产端刚需"。

## 1. 定位锚(双锚,缺一不可)

**篮子(用户选定)**:可控 Agent 编排层 —— 顺着投资人已热的 agent 叙事,用"可控"当楔子切开拥挤的自主 agent 赛道。

**但"可控"单独不够深**:LangGraph 给工程师的就是可控,n8n 某种程度也可控。只讲可控 → 掉进拥挤的 agent infra 赛道,靠执行力拼杀。**真正进无人区的是"可控 × 领域知识库"的乘积。**

### 一句话定位(双锚最终版)
> **"我们做的是面向企业生产的、由领域知识驱动的可控 Agent 编排层。**
> **别人的 Agent 把资料当参考、读完可以无视;我们把领域专业知识变成流水线上的关卡裁判——计划不合规就打回,产出不达标就否决。可控架构是骨架,领域知识库是灵魂,两者相乘,通用 AI 才变成领域专家。"**

### 为什么两者必须捆在一起(核心洞察)
- **光有"可控"**:得到纪律严明但平庸的流水线——不跑偏,但产出只是通用 AI 平均水平。可控产生确定性,不产生质量。
- **光有"领域知识库"(RAG)**:知识是被动参考资料,AI 可无视——进不了控制流,治不住产出。
- **两者相乘**:可控架构提供**关卡**(计划闸/产出闸,流程图上必经节点);领域知识库提供**裁判**(在关卡上用专业铁律否决不合格的计划与产出)。**= 领域知识第一次有了强制执行力。** "每个工位站着真专家"那句话才被兑现——专家不是摆设,是有否决权的关卡裁判。

## 2. 电梯版(30 秒,已按两条约束改写)
> 我们做的是面向企业生产的、由领域知识驱动的**可控 Agent 编排层**。
> AI Agent 已经很强——强在**自主探索**:给一个开放任务,一个聪明大脑自己规划自己闯。这正是个人和工程师爱用它的原因。
> 可企业生产要的是另一件事:**同样输入,每次都得到同样的、达标的产出**——可控、可复现、可追溯。这不是 Agent 不够好,而是它优化的方向和"把生产流程交出去"本就不在一条轴上。
> 我们填这个错配。**Graph Agent 把一份人能读懂的文档,编译成一条可控的生产流水线——流程固定,但每个工位都站着一个真正的 AI 专家;而这些专家受一个领域知识库治理,计划不合规打回、产出不达标否决。Graph Studio 让业务负责人本人,通过对话就能搭建和调试它,所见即所得。**
> 我们自己就是内容科技公司,这套引擎源于生产端真实刚需;现在用它造两个垂直产品——AI 影视工业管线、AI 软件研发系统——既验证引擎,也跑在真实负载上。

## 3. 诚实边界(对投资人务必分层:已交付 vs 路线图)
- **已交付(真代码、能跑)**:Graph Agent 引擎 v0.3.0 —— 控制优先的多阶段编译架构(文档→DAG)、多模型网关容灾、全链路可观测、测试即生产。**"可控"那一锚立得住,讲得硬气。**
- **进行中**:Graph Studio 的 PM-Copilot 体验、测试-生产闭环打磨。
- **路线图/未落地**:**领域知识库大脑(假说-演绎自进化系统)——钩子已埋、核心待建**;两个垂直产品在概念+研究阶段(有白皮书/行业研究,无产品代码)。
- **讲法铁律**:双锚里,"可控"是已交付,"领域知识库"是路线图。**把灵魂讲成愿景没问题(投资人买想象空间),但别讲成已交付**——尽调一问"demo 给我看知识库否决产出"就穿帮。标签锚在实交付,故事讲在路线图,分开。
