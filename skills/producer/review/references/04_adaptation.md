# 改编与旁白质量标准：沉浸式第一人称协议

## 第一性原理：旁白即“情绪共振引擎”
旁白不是客观的剧情解说，而是**主角主观情绪的直接投射**。它的核心机制是**强制代入（Forced Empathy）**。
观众不是在“看”一个故事，而是通过“我”的眼睛、心跳和呼吸在“经历”这个故事。

## 旁白机制：主观视角与节奏控制

### 身份与语气的结构化锚定
- **绝对第一人称**：必须使用“我”的视角。语气必须带有强烈的角色性格（如：冷酷生存者的简短笃定、病娇的反常呢喃）。
- **去冗余机制**：旁白绝对不能解释画面已经清晰展示的物理动作（如“我举起了刀”）。旁白只负责传达**画面无法直接展示的心理博弈、痛感、杀意或绝望**。
- **语料禁忌**：严禁使用“这时候/就在此刻/突然”等廉价的网文套话。情绪的突变应该通过**断句、留白和画面冲击**来完成。

### 节奏的三维状态机（State Machine）
- **高压/战斗态（High-Tension）**：极短句、省略主语、动词前置。模拟肾上腺素飙升时的急促呼吸。
- **压抑/潜行态（Stealth/Dread）**：短句 + 长停顿（...）。模拟屏住呼吸、极度专注或恐惧的压迫感。
- **情感/爆发态（Emotional Release）**：情绪宣泄，词汇极度浓缩，直击痛点或爽点。

## 画面承载力：Visual Cue 的语义压缩

### Visual Cue 不是场景标签，是“画面构想”
- **低熵要求**：每个 segment 的 `visual_cue` 必须是高密度的潜空间锚点，直接指导画面生成。
- *错误示范*（高熵/模糊）："超市内部画面，很恐怖"
- *正确示范*（低熵/高密度）："废弃超市货架间，白衣女子的生锈巨型剪刀在昏暗中缓缓开合，冷蓝色顶灯疯狂闪烁"
- **互补机制**：画面的情绪张力必须**大于或等于**旁白的情绪张力。旁白负责“内”，画面负责“外”，两者形成共振。

## 情绪密度：防流失协议

### 60秒情绪阻断机制
- **高频刺激**：爽剧的每一分钟都必须包含至少一次强烈的情绪波动（冲突升级、爽点释放、极致恐惧）。
- **零平叙容忍**：连续 60 秒的“平铺直叙”（无情绪波动的背景交代或赶路）是绝对的质量红线，必须被压缩或剪辑掉。

## 零样本压力测试：审核检查清单
- [ ] 旁白是否完全去除了“解释画面”的冗余，专注于心理与情绪的传达？
- [ ] 旁白的断句和节奏是否匹配了当前场景的“呼吸频率”（战斗急促、潜行压抑）？
- [ ] 每个 `visual_cue` 是否都是高密度的画面构想，而非模糊的场景标签？
- [ ] 是否存在连续的“平叙”段落导致情绪密度下降？
- [ ] 关键的 P0 核心事件（骨架）是否被完整且高张力地保留？
