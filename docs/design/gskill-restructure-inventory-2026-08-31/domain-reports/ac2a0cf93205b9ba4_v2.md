## 3. 证据

勘察对象:新仓 `D:\coding\graph-skill-runtime`。命令与输出原样贴出,取证日期 2026-09-02。
计数基准取 v1 自己声明的勘察基准 `230fc3bd`(v1 开头:「新仓 `D:\coding\graph-skill-runtime`

### 证据一 · 三个时间点上的 shim 引用数都是 44

```
$ git grep -l legacy_fixture_adapter 1e1a3540 -- 'tests/*' | grep -v tests/legacy_fixture_adapter.py | wc -l
44
$ git grep -l legacy_fixture_adapter 230fc3bd -- 'tests/*' | grep -v tests/legacy_fixture_adapter.py | wc -l

$ git grep -l legacy_fixture_adapter 2638fd6c -- 'tests/*' | grep -v tests/legacy_fixture_adapter.py | wc -l

```

三条命令都排除 shim 文件自身(`tests/legacy_fixture_adapter.py`),数的是**导入方**。
`1e1a3540` = #5「feat: adopt portable gSkill v1 format」,`230fc3bd` = #10 = v1 的勘察基准,
`2638fd6c` = #12 = 原生语料三张 PR 开工前的最后一提交。

这三个点之间也没有波动——把区间里**每一个**提交都数一遍,取值只有 44 一个:

```
$ for c in $(git rev-list --reverse 1e1a3540..2638fd6c); do git grep -l legacy_fixture_adapter $c -- 'tests/*' | grep -v tests/legacy_fixture_adapter.py | wc -l; done | sort -u
44
$ git rev-list --count 1e1a3540..2638fd6c

```

所以**从新格式落地到语料改造开工的这 13 个提交上,这个数恒为 44**;v1 勘察当刻的真值也是 44,
不是它当时碰上的某个瞬时值。

## 4. 订正对原判断的影响

- **判断方向不变。** 44/252 ≈ 17% 仍是「converter 位于测试热路径上」:一份 converter 缺陷会同时
  污染约六分之一的行为测试,而不是 v1 说的三分之一。量级从「三分之一」降到「六分之一」,不改变
  「不能靠这批测试证明新格式的原生行为」这个结论。
- **该风险此后已被消除,消除过程本身也是证据。** 原生语料三张 PR 把棘轮
  `tests/test_native_v1_corpus_ratchet.py` 的上限逐张收干,shim 在最后一张里删除:

  ```
  $ git log --oneline -5 -- tests/test_native_v1_corpus_ratchet.py
  676285ca test: finish the native v1 corpus, delete the converter shim (3/3) (#21)
  53539677 test: author the remaining tests/core corpus natively in portable gSkill v1 (2/3) (#20)
  6a9959d2 test: author the first 19 corpus modules natively in portable gSkill v1 (#19)

  $ for c in 6a9959d2 53539677 676285ca; do git show $c:tests/test_native_v1_corpus_ratchet.py | grep -m1 "^MAX_LEGACY_CORPUS_MODULES"; done
  MAX_LEGACY_CORPUS_MODULES = 25
  MAX_LEGACY_CORPUS_MODULES = 4
  MAX_LEGACY_CORPUS_MODULES = 0
  ```

  即 45 → 25(#19)→ 4(#20)→ 0(#21);`tests/legacy_fixture_adapter.py` 在 `676285ca` 之后
  不再存在于新仓 `main`。**因此本条警讯在新仓当前 `main` 上已不成立**,订正的数字描述的是
  v1 勘察当刻(2026-08-28)的状态。
