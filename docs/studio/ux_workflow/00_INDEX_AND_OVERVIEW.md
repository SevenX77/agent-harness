# Skill Studio UI/UX 工作流总览

**目标**: 定义产品经理 (PM) 在 Skill Studio 中的完整工作流闭环，并为每个节点的界面 (UI) 与交互 (UX) 提供详细的设计参考。

## 工作流节点索引 (Workflow Nodes)

1. [01_DISCOVERY_AND_INIT.md](./01_DISCOVERY_AND_INIT.md) - 发现与初始化 (入口与环境准备)
2. [02_EDIT_AND_COMPILE.md](./02_EDIT_AND_COMPILE.md) - 编辑与编译 (SKILL.md 编写与实时校验)
3. [03_PREDICT_AND_BASELINE.md](./03_PREDICT_AND_BASELINE.md) - 预测与基线 (Mock 测试与 Golden 数据打磨)
4. [04_RUN_AND_TRACE.md](./04_RUN_AND_TRACE.md) - 真实运行与观察 (真实 LLM 消耗与时间轴)
5. [05_DEBUG_AND_RESUME.md](./05_DEBUG_AND_RESUME.md) - 调试与断点重试 (人工干预与错误恢复)
6. [06_EVAL_AND_PUBLISH.md](./06_EVAL_AND_PUBLISH.md) - 评估与交付 (结果 Diff 与一键上线)

> **设计原则**: 业务流先于界面流。确保 PM 的每一步操作都有明确的目的、清晰的反馈，以及失败时的退路。
