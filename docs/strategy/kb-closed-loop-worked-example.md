# KB 闭环样例:领域知识如何在 plan 端纠偏、review 端验收

> **日期**: 2026-06-03
> **性质**: 叙事化样例(worked example),不是代码改动。用真实素材演示"知识当裁判"的完整闭环。
> **载体**: AI-story-forge 的 `adaptation_v1_sandbox` skill(把小说章节改编成解说驱动型短剧分镜)。
> **真实素材**: 项目 `013_躺赢`(《开局天灾,我靠囤百亿物资躺赢》),姜宁末世重生囤货题材,第 1 章原文。
> **KB 本体**(真实存在于 skill 中):
> - `golden_rules.md` — 三条黄金法则:①三秒生死线 ②VO/对白严格分工 ③反差即正义
> - `voice_and_rhythm_rules.md` — 声音武器库(VO/OS/对白)+ 视觉节奏(蒙太奇 0.5-1.5s / 稳态长镜头 3-5s)+ 制片人推演逻辑链
> - **核心红线**:音画分离(画面演动作,VO/OS 讲剧情逻辑与伏笔,严禁"看图说话")
>
> **用途**: 给投资人/团队讲清"可控架构(骨架)× 领域知识库(灵魂)"如何在一条真实生产流水线上落地。对应 `investor-pitch-positioning.md` 的双锚定位。

---

## 0. 这份文档要演什么

一句话:**同一段小说原文,经过四种处理,质量天差地别——而拉开差距的不是模型,是 KB 有没有在两个关卡上行使裁判权。**

四种处理,逐级递进:
- **形态 A**:Agent 裸跑(无 KB)——通用 AI 的"平均水平",看图说话。
- **形态 B**:KB 在 **plan 端**纠偏(现状已有)——制片人用 KB 把策略写对,但出口无人把关。
- **形态 C**:形态 B 的产出**没有 review**——编剧没完全执行策略,缺陷溜过。
- **形态 D**:**review 端**用 rubric 验收(要补的闭环)——逐条按 KB 公理打分,不达标硬打回重写,得到合格产出。

闭环 = A→D 的完整链路。**plan 端纠偏 + review 端验收,两个关卡都由 KB 当裁判,才叫闭环。**

## 1. 输入:一段真实小说原文(第 1 章节选)

> 姜宁睁开眼猛地从床上坐起,汗水顺着额头淌下……这是末世前住的公寓?接连收到短信提醒……全是关于超强台风"菜刀"预计将于 17 日凌晨登陆沿海的消息……姜宁用力拧着胳膊,剧痛提醒这不是梦,她真的重生了。重生在那场揭开末世篇章的超强台风前三天。
>
> (取过刀片划破手指将血珠滴落在吊坠 → 进入空间 → 拉物资清单 → 给发小张超转 5 万订紧缺药 → 看到限量版 AJ → 出门退掉 8600 元 AJ 换囤粮 → 订防爆门窗)

**这段戏的客观事实**:重生惊醒 / 确认时间线 / 滴血认空间 / 囤货决心 / 退 AJ 立场宣言。
**这段戏的爽点(来自 drama_dna)**:H1 退 AJ 换囤粮("不要爱情要活命"立场宣言,开场 3 秒)、H3 信息差("她知道,别人不知道")。

---

## 2. 形态 A — Agent 裸跑(无 KB):通用 AI 的平均水平

如果把原文直接丢给一个没有 KB 的通用 agent,让它"改成短剧分镜",典型产出:

| # | video_audio(画面) | voice_text(声音) |
|---|---|---|
| 1 | [姜宁从床上坐起,擦汗 \| 4s] | 【VO】姜宁猛地从床上坐起来,擦了擦额头的汗。 |
| 2 | [姜宁看手机,屏幕显示台风短信 \| 4s] | 【VO】她拿起手机,看到很多条台风预警短信。 |
| 3 | [姜宁拧自己胳膊 \| 3s] | 【VO】她拧了一下胳膊,发现不是做梦,自己重生了。 |
| 4 | [姜宁划破手指滴血在吊坠上 \| 4s] | 【VO】她划破手指,把血滴在吊坠上。 |

**问题(全是 KB 红线违规,但裸 agent 不知道):**
- ❌ **音画分离全面失守**:每一条 voice_text 都在复述画面动作("坐起来/看手机/拧胳膊/滴血")= 教科书级的"看图说话"。声音通道被浪费,零信息增量。
- ❌ **三秒生死线没了**:开场是"坐起来擦汗",平淡,3 秒内观众划走。
- ❌ **VO 全程过去式总结口吻**("看到了""发现了"),违反 VO"必须进行时、带观众探索未知"的第一性原理。
- ❌ **声音武器单一**:全程 VO,没有 OS(内心独白)制造代入,没有信息差张力。

**这就是"光有可控、没有 KB"的天花板**——哪怕流程跑通了,产出也只是 60 分以下的平庸。**可控产生确定性,不产生质量。**

## 3. 形态 B — KB 在 plan 端纠偏(现状,已实现)

### 3.1 纠偏机制:KB 注入制片人,产出"策略",再交给编剧

现状代码(`producer_dispatcher.py`)把 `voice_and_rhythm_rules.md` **注入制片人 LLM 的 system prompt**,制片人结合大纲/DNA/beats,产出每场的**策略批注**;再由 `writer_dispatcher.py`(同样注入 KB)按策略写。

**这是 plan 端纠偏 = 入口处用 KB 把"该怎么做"先定下来。** 对照:

**【纠偏前】agent 自己想的 plan(裸):**
> "把第 1 章按时间顺序改成分镜,旁白讲清发生了什么。"
> → 直奔"看图说话",因为它的默认认知就是"旁白=解说画面"。

**【纠偏后】KB 纠正出的 producer 策略(真实机制产出):**
```json
{
  "audience_psychology_analysis": "本段核心是'信息差俯视爽'(H3)+'立场宣言爽'(H1)。观众要的不是'看姜宁做了什么',而是钻进她脑子里,体验'我知道天要塌、而全世界还蒙在鼓里'的智力优越感,以及'老娘不要爱情要活命'的代偿快感。",
  "scene_strategies": [
    {
      "scene_id": "OBJ_SC_01",
      "producer_directives": "开场即生死线。这是'重生设定+信息差'戏,不是流水账。必须 3 秒内用'重生'的认知冲击抓住人,而不是'坐起来擦汗'。",
      "beats_treatment": "b1(惊醒)用【情绪轰炸蒙太奇 0.5-1s】闪回前世惨死画面,瞬间注射肾上腺素;b2(看台风短信)画面稳住【稳态长镜头】,VO 进行时抛设定'菜刀台风,三天后登陆——这是末世的开场哨';b3(拧胳膊)插入【OS】'好疼……不是梦,我真的回来了',情绪浓烈、现在进行时;严禁 VO 复述'她看手机/她拧胳膊'。"
    },
    {
      "scene_id": "OBJ_SC_02",
      "producer_directives": "退 AJ = 全剧第一个立场宣言钩(H1),要当爽点炸,不能当日常拍。",
      "beats_treatment": "退 AJ 动作用【对白】对抗(店员质疑 vs 姜宁不容置疑)+【OS】算账'8600 块够囤两三年的米面油,要什么男人';用 VO 压缩交代'前世他收我礼物、要我空间、台风天带校花吃我囤粮'——反差即正义。"
    }
  ]
}
```

**看清纠偏发生了什么:**
- KB 把 plan 从"按时间复述"扭转成"按观众心理(信息差/立场宣言)重组声音武器"。
- KB 提供了裸 agent 不具备的领域判断:哪里该蒙太奇、哪里该插 OS、哪里该 VO 压缩、哪句严禁看图说话。

> ⚠️ **但注意纠偏的局限**:现状 plan 端是"KB 写进 prompt 当指导"——它**让编剧更可能写对,但不保证写对**。制片人策略说得再好,编剧 LLM 是否逐条执行,**出口没有人检查**。这就引出形态 C。

## 4. 形态 C — 有 plan 纠偏,但产出无 review(现状的缺口)

编剧拿着上面的完美策略去写,**实际产出往往只执行了一部分**(LLM 的常态:抓大放小、回退到舒适区)。真实可能的编剧产出:

| # | video_audio | voice_text | 执行情况 |
|---|---|---|---|
| 1 | [前世惨死闪回:断壁残垣中姜宁倒地 \| 1s 碎切] | 【OS】"好疼……这不是梦。我真的回来了!" | ✅ 蒙太奇+OS,执行到位 |
| 2 | [手机屏幕台风预警短信特写 \| 4s] | 【VO】"菜刀台风,三天后登陆。这是末世的开场哨,而整座城市还在睡。" | ✅ VO 进行时+信息差,到位 |
| 3 | [姜宁划破手指,血珠滴落吊坠 \| 4s] | 【VO】"她划破手指,把血滴在吊坠上,吊坠发出了光。" | ❌ **回退到看图说话** |
| 4 | [姜宁在 AJ 店退货,店员惊讶 \| 4s] | 【VO】"她把限量版 AJ 退掉了,换了 8600 块钱。" | ❌ **看图说话 + 爽点拍成流水账,H1 立场宣言丢失** |

**缺口暴露**:第 3、4 条编剧没执行策略——第 3 条退回看图说话,第 4 条把"退 AJ 立场宣言"这个全剧第一爽点(H1)拍成了平淡流水账。**策略是对的,执行漏了,而没有任何关卡拦住它。** 这条片子就这样进入下一环节,缺陷沉淀。

**这就是"只有 plan 端纠偏、没有 review 端验收"的开环。** KB 在入口当了顾问,在出口却不在场。

---

## 5. 形态 D — review 端用 rubric 验收(要补的闭环)

### 5.1 验收机制:rubric 的评分维度 = KB 公理

编剧产出后,**引擎强制**调用 producer review(不是 agent 自觉调用),按 KB 公理逐条打分。**rubric 的每一个维度,直接就是 golden_rules + voice_rhythm 里的一条**:

| rubric 维度(= KB 公理) | 检查 | 严重度 |
|---|---|---|
| 音画分离 | voice_text 是否复述画面动作 | critical |
| 三秒生死线 | 开场是否极致冲突/奇观 | critical |
| VO/OS/对白分工 | 声音武器是否用对场景 | warning |
| VO 时态 | 是否进行时(非过去式总结) | warning |
| 爽点兑现 | drama_dna 的 H1-H5 钩子是否落地 | critical |
| 镜头时长 | 稳态 3-5s / 蒙太奇 0.5-1.5s | suggestion |

### 5.2 producer review 给形态 C 产出的真实意见

```json
{
  "passed": false,
  "score": 5,
  "issues": [
    {
      "severity": "critical",
      "category": "音画分离",
      "scene": "分镜 3",
      "description": "voice_text『她划破手指,把血滴在吊坠上,吊坠发出了光』完全复述画面动作,是教科书级看图说话。画面已经在演滴血,声音必须讲画面背后的东西。",
      "recommendation": "VO 改为交代认知/伏笔,例如:【OS】'前世苏梦瑶就是从这空间里,当着我饿晕的面舔冰淇淋——这一世,它是我的。'(滴血动作交给画面,声音讲空间的来历与夺回的决心)"
    },
    {
      "severity": "critical",
      "category": "爽点兑现",
      "scene": "分镜 4",
      "description": "退 AJ 是全剧第一个立场宣言钩(H1,drama_dna 标注'开场3秒内、瞬间锁定目标受众'),当前拍成了'退掉换钱'的流水账,最强情绪点被浪费。",
      "recommendation": "用【对白】制造对抗(店员:'这可是限量款,多少人抢'/姜宁:'我要它没用,我要活命'),配【OS】算账'8600 够囤两三年米面油'。把动作拍成价值观宣言。"
    },
    {
      "severity": "warning",
      "category": "VO时态",
      "scene": "分镜 3-4",
      "description": "两处 VO 都是过去式总结口吻('她划破''她退掉'),违反 VO 进行时第一性原理,观众被推到旁观者位置,失去代入。",
      "recommendation": "改用现在进行时/第一人称当下感,让观众和'我'一起经历。"
    }
  ],
  "summary": "策略方向正确,但执行回退:2 处看图说话 + 第一爽点未兑现。评分 5/10,低于 7 分阈值且含 critical,打回重写。"
}
```

### 5.3 引擎硬打回(这是"可控"的兑现)

`passed: false` → 引擎**自动**把 issues 注入下一轮编剧的 user message(`--- 校验反馈 ---`),**强制**重跑编剧(`retry_target`),最多 N 次。**LLM 绕不过去——这不是建议,是关卡。**

### 5.4 编剧改完后的合格产出

| # | video_audio | voice_text |
|---|---|---|
| 1 | [前世惨死闪回:断壁残垣姜宁倒地 \| 1s 碎切] | 【OS】"好疼……这不是梦。我真的回来了!" |
| 2 | [手机台风预警短信特写 \| 4s] | 【VO】"菜刀台风,三天后登陆。这是末世的开场哨——而整座城市,还在睡。" |
| 3 | [姜宁划破手指,血珠滴落吊坠,吊坠骤亮 \| 4s] | 【OS】"前世苏梦瑶就是从这空间里,当着我饿晕的面舔冰淇淋。这一世,它是我的。" |
| 4 | [AJ 店,姜宁推回鞋盒,店员错愕 \| 3s] | 【对白】店员:"这可是限量款!" 姜宁:"我要它没用。我要活命。" |
| 5 | [退款单 8600 → 闪过米面油囤货清单 \| 2s 快剪] | 【OS】"8600,够囤两三年的口粮。要什么男人。" |

**对照形态 A→D 的同一段戏:**
- 音画分离:A 全违规 → D 声音全部讲"画面背后的东西"(空间来历、认知、立场)。
- 三秒生死线:A 擦汗开场 → D 前世惨死闪回 1s 碎切。
- 爽点:A/C 流水账 → D 退 AJ 拍成"我要活命"价值观宣言(H1 兑现)。
- 声音武器:A 全程 VO → D 用 OS 代入 + 对白对抗 + VO 压缩,层次分明。

## 6. 闭环全貌

```
小说原文
   │
   ▼
┌─────────────────────────────────────────────┐
│ PLAN 端                                       │
│  制片人 ← 注入 KB(声音武器库/黄金法则)        │
│  产出:观众心理分析 + 每场声音武器策略          │  ← 纠偏:把"按时间复述"扭成"按观众心理重组"
└─────────────────────────────────────────────┘
   │ 策略
   ▼
  编剧(注入 KB)产出 script_draft
   │
   ▼
┌─────────────────────────────────────────────┐
│ REVIEW 端(要补的闭环)                         │
│  引擎强制调 producer review                    │
│  rubric 维度 = KB 公理,逐条打分                │
│   ├─ passed → finish(闭环完成)                │
│   └─ failed → 注入 issues、硬打回编剧重写 ──┐  │  ← 验收:KB 在出口行使否决权
└────────────────────────────────────────────│─┘
   ▲────────────────────────────────────────┘
   (最多 N 轮)
```

**两个关卡,一个灵魂**:plan 端 KB 纠正"该怎么做",review 端 KB 否决"做得不对的"。**入口出口都由领域知识把关,这才是闭环;缺了 review 端,KB 就只是个可被无视的顾问。**

## 7. 给投资人的一句话(本样例的落点)

> "同一段原文、同一个模型,差别只在 KB 有没有在两个关卡上当裁判:
> 裸 agent 写出来是'她拿起手机看短信'——看图说话的平庸;
> 我们的引擎里,KB 在入口把策略纠正成'信息差俯视',在出口把'看图说话'和'丢掉的爽点'**硬打回重写**,直到达标才放行。
> **可控架构保证每段产出都必须过这道关,领域知识库定义这道关的标准——这就是把通用 AI 变成领域专家。**"
